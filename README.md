# Souvik Sinha — Portfolio

A bold, colorful personal portfolio built with plain HTML, CSS and JavaScript. No build step.

## Files

- `index.html` — page content (edit your bio, skills, projects and links here)
- `styles.css` — colors, layout and animations (change the palette in `:root`)
- `script.js` — mobile menu, rotating tagline, count-up stats, scroll reveal

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Publish on GitHub Pages

1. Go to the repository's **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**, pick the branch and `/ (root)`.
3. Save. The site appears at `https://souviksinha-gif.github.io/souviksinha-gif/` after a minute or two.
